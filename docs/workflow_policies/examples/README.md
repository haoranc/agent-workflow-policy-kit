# Examples

These bundles are **examples** to illustrate the structure and the post-run update loop.

## Included bundles
- `deployment/` — generic deployment policy bundle (safety-critical)
- `incident_response/` — generic incident response policy bundle (coordination-critical)

Copy an example into `docs/workflow_policies/<your_workflow>/` and adapt:
- replace placeholder commands
- adjust safety guardrails to your environment
- tailor KPIs and “Definition of Done” to your team
